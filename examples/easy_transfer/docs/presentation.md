# 1분 발표 (메인 예시 · M6-05 최종 · M6-06 선별 발표 대비)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: **작성 형태를 보여주는 가상 기록** — 시각·제출·로그아웃 체크는 예시일 뿐 실제로 한 것이 아닙니다. 여러분은 실제로 한 것만 적으세요.

|랜딩 섹션|시간|말할 문장 (확인한 것만)|
|---|---|---|
|① · ② · ③|20초|「전화번호만 알면 30초에 보내는 송금 데모입니다. 2014년에 이미 4,034만 명이 폰으로 은행을 썼지만, 송금 한 번은 2~3분 걸렸습니다. 회식비 만 원을 보내려다 보안카드가 없어 ‘집에 가서 보낼게’ 하고 잊는 대학생을 위해 만들었습니다.」|
|④ 시연|25초|「번호, 금액, 비밀번호 — 한 화면에 하나씩, 세 번이면 끝납니다.」 (010-1234-5678 · 10,000 · 1234)|
|⑤ · ⑥|15초|「정상·빈칸·잘못된 입력을 확인했습니다. 실제 송금은 은행 연결이 필요해 오늘은 흐름만 만들었고, 다음엔 더치페이 나누기를 붙이겠습니다.」|

- 뺀 문장(금지): 「토스보다 빠릅니다」(비교 측정 안 함) · 「안전합니다」(보안 검증 안 함)
- 예상 질문 1: 「진짜 돈이 가나요?」 → 「아니요, 교육용 데모이고 계좌 연결이 없습니다.」
- 예상 질문 2: 「30초는 잰 건가요?」 → 「기사 수치입니다. 데모는 완료 화면에 제가 걸린 시간을 보여 줍니다.」

- 받은 질문(발표했다면): (예시) 「보안은 어떻게 하나요?」 → 「오늘은 흐름만 만들었고 실제 서비스는 은행 연동·보안 심사가 필요합니다」
