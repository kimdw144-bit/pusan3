# 주제 (메인 예시)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

**주제 한 문장**: 친구에게 소액을 보내려는 대학생이 보안카드·공인인증서 절차 때문에 송금을 미루고 잊는다.

- 곤란한 사람: 회식비 1만 원을 보내야 하는데 보안카드가 서랍에 있는 대학생 (가설)
- 근거: data_sources.md 1·2번
- 변화(기존 방식 vs 개선 방식 · 기간별 추이 데이터가 없는 주제라 비교로 함): 송금 한 번 약 2~3분 → 30초 (한국경제 2018-01-14) · 계산: 30초 ÷ 150초(2분 30초) = 0.2 → 약 1/5 · 해석: 단계를 없애면 시간이 크게 준다 · 한계: 기사에 실린 대략의 시간이며 측정 조건은 알 수 없다
