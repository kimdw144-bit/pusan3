# 요구사항 (메인 예시)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

| ID | 입력 | 기대 결과 (구현 전에 적음) |
|---|---|---|
| R-01 정상 | 010-1234-5678 · 10,000 · 1234 | 「010-1234-5678 님께 10,000원」 완료 화면 · 걸린 시간 · 기존 약 2~3분(data.js 출처) |
| R-02 빈칸 | 번호를 비움 | 「받는 사람 전화번호를 입력하세요」 · 다음으로 안 넘어감 |
| R-03 오류 | 010-123 · 011-1234-5678 · -500 · 비밀번호 123 | 번호 「전화번호는 010으로 시작하는 11자리 숫자예요」 · 금액 「금액은 1원~200만 원 사이 숫자로 입력하세요」 · 비밀번호 「비밀번호는 숫자 4자리예요」 · 입력 그대로 · 다음으로 안 넘어감 |
