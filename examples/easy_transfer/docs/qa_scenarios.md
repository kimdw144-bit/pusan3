# 단위·통합 테스트 설계 (메인 예시 · M5-08)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

단위 테스트(UT) = app.js 함수 하나에 값을 넣은 결과 · 통합 테스트(IT) = app.html에서 입력 → 처리 → 화면까지 · 배포 확인은 M6-04에서 같은 흐름을 배포 주소로.

## 단위 테스트

|테스트 ID|R-ID|대상 함수|입력|기대 결과|확인 방법|
|---|---|---|---|---|---|
|UT-01|R-01|validatePhone · validateAmount · validatePin · receipt|010-1234-5678 · 10,000 · 1234|영수증 to=010-1234-5678 · amount=10,000원 · steps=3|test.html 더블클릭|
|UT-02|R-01|receipt|아무 값|before = data.js의 「2~3분」|test.html|
|UT-03|R-02|validatePhone · validateAmount · validatePin|빈칸|「받는 사람 전화번호를 입력하세요」 · 「보낼 금액을 입력하세요」 · 「비밀번호 4자리를 입력하세요」|test.html|
|UT-04|R-03|validatePhone|010-123 · 공일공 · 011-1234-5678|ok=false · 「전화번호는 010으로 시작하는 11자리 숫자예요」|test.html|
|UT-05|R-03|validateAmount|-500 · 0 · 2000001 · 만원|ok=false · 「금액은 1원~200만 원 사이 숫자로 입력하세요」|test.html|
|UT-06|R-03|validatePin|123 · 12a4|ok=false · 「비밀번호는 숫자 4자리예요」|test.html|
