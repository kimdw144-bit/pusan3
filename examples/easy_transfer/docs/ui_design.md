# UI 설계 (메인 예시 · M5-08)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

## 랜딩의 시각 요소
|요소|보여 줄 내용|연결 문서·R-ID|확인 방법|
|---|---|---|---|
|문제 한 줄|"만 원 보내는데 왜 2~3분?"|topic · ①|랜딩 첫 화면|
|핵심 숫자|4,034만 명 · 약 2~3분|data_sources · ②|출처·기준일 표시|
|불편 순간|보안카드가 서랍에|persona·journey · ③|사용자 흐름 설명|
|전·후 흐름|기존 4단계 → 데모 3단계|F-01 · ④|앱 버튼 연결|
|앱 미리보기|전화번호·금액·비밀번호|R-01|app.html 직접 실행|
|한계|교육용 데모·실제 송금 없음|⑦|랜딩 하단|

## 상태별 화면
- R-01 정상: 완료 금액·받는 사람·걸린 시간 표시.
- R-02 빈칸: 안내 문구, 다음 단계로 이동하지 않음.
- R-03 오류: 오류 문구와 기존 입력 유지.

원칙: 공개 UI에서는 정보 위계·버튼 위치만 관찰한다. 타사 로고·화면 캡처·글꼴·문구를 복사하지 않고 원본 CSS·SVG로 만든다.
