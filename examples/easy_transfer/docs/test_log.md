# 테스트 결과 (메인 예시 · M6-02)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: **실제 로컬 실행 결과** (2026-09-18 · 자동 브라우저로 같은 순서를 눌러 확인)

실행: 2026-09-18 · 로컬(app.html·test.html 더블클릭과 같은 file:// 환경) · 자동 브라우저로 같은 순서를 눌러 기록

|날짜|테스트 ID|R-ID|입력|기대 결과|실제 결과|판정|
|---|---|---|---|---|---|---|
|09-18|UT-01~06|R-01~03|test.html|6개 모두 PASS|「6/6 통과」|PASS|
|09-18|IT-01|R-01|010-1234-5678 · 10,000 · 1234|완료 화면 · 기존 2~3분|「010-1234-5678 님께 10,000원 · 걸린 시간 1초 · 기존 약 2~3분」|PASS|
|09-18|IT-02|R-02|번호 빈칸|안내 · 2/3로 안 넘어감|「받는 사람 전화번호를 입력하세요」 · 1/3에 머묾|PASS|
|09-18|IT-03|R-03|010-123 / 011-1234-5678 / -500 / 123|칸마다 안내 · 입력 유지|세 안내 모두 표시 · 3/3에 머묾 · 입력 123 유지|PASS|
|09-18|IT-04|R-01|랜딩 ④ 버튼|app.html 열림|app.html 열림|PASS|

걸린 시간 1초는 자동 입력이라서다. 사람이 누르면 10초 안팎(강의 캡처 11~12초).
