# 린캔버스 (메인 예시)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

| 칸 | 내용 | 사실/가설 |
|---|---|---|
| 1 문제 | 소액 송금 한 번에 2~3분 · 보안카드·인증서 · 대안: 현금, 「이따 보낼게」 | 근거 2 |
| 2 고객 | 회비·더치페이가 잦은 20대 · 첫 고객: 대학 동아리 | 가설 |
| 3 가치제안 | 계좌번호·보안카드 없이 30초 송금 | 근거 2 |
| 4 솔루션 | 전화번호 + 금액 + 비밀번호 | — |
| 5 채널 | 돈을 받은 친구가 알림으로 알게 됨 | 가설 |
| 6 핵심지표 | 한 주 송금 건수 | — |
| 7 비용 | 은행 연결 · 보안 · 고객센터 | 가설 |
| 8 수익 | 송금은 무료 → 이후 금융 서비스 | 가설 |
| 9 경쟁우위 | 은행 자동출금(CMS)을 연결해 인증서 없이 | 공개 기사 |

★ 가장 위험한 가정: 사람들은 은행 앱이 아닌 곳의 송금도 믿고 쓸 것이다
