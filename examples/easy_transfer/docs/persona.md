# 페르소나 (메인 예시 · 가상 인물)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

- 이름: 민수 (23세 · 대학생 · 동아리 회원) — 가상 인물
- 숫자: 한 달 송금 8번(회비·회식비·더치페이) · 건당 1~2만 원 (가설)
- 성향: 귀찮은 일은 미루는 편 (가설)
- 목표: 모임 돈을 제때 깔끔하게 보내기
- 불편 3: 계좌번호를 다시 물어야 함 · 보안카드가 서랍에 · 인증서 비밀번호를 자꾸 잊음
- 기존 방법: 현금 · 「집에 가서 보낼게」
- 계기: 회식 뒤 총무에게 「아직 안 보냈어?」를 세 번 들음
- 거절할 이유: 「은행 앱도 아닌데 믿어도 되나?」 (6단계 피드백으로 추가 · 가설)
