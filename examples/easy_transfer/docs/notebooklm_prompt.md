# NotebookLM 명령 (메인 예시)

> 수업용 예시. 토스의 첫 문제(2015년 이전 송금)를 공개 기사로 재구성했고, 인물 민수는 가상입니다. 토스 내부 문서가 아닙니다.

> 기록 상태: 기획 문서 예시(공개 기사로 재구성 · 가설 표시 포함)

business_plan.md 하나만 소스로 올린 뒤 아래 명령을 붙인다.

```text
업로드한 business_plan.md만 근거로 한국어 발표자 슬라이드 10장 이내를 만들어줘. 새 숫자·시장 규모·고객 사례·출처를 만들지 말고 [사실]·[가설]·[검증] 표시를 유지해. 순서는 현황 → 문제·대안 → 페르소나·여정 → 고객·시장·가치 → MVP·RICE → UI·요구사항 → 채널 → 수익·비용 → 핵심지표·마일스톤 → 한계·다음 검증으로 해. 각 장 하단에 문서 내 출처 또는 리서치 필요를 표시해.
```
