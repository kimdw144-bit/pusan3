# 30초 송금 데모 (3일차 메인 예시 · 교육용)

토스의 첫 문제(2015년 이전 송금: 계좌번호·보안카드·공인인증서로 2~3분)를 공개 기사로 재구성해, 오늘 수업 13단계를 그대로 밟아 만든 예시입니다.
- index.html 랜딩(①~⑦ = 1분 발표 순서) · app.html 한 화면 한 가지 3단계 · data.js 공개 기사 숫자 · test.html 자동 검사
- docs/ 기획 문서(주제·근거·린캔버스·페르소나·저니맵·MVP·요구사항) — 인물은 가상, 토스 내부 문서가 아님
- 실제 송금·계좌 연결 없음. 특정 회사의 로고·글꼴·화면을 쓰지 않았습니다.
