# 사업계획서 · M5-07에서 완성하고 M6에서 실제 결과만 보완

> 이 문서는 마지막 25분에 새로 쓰지 않습니다. **M5-07에서 Lean Canvas·MVP·RICE까지 포함한 MD를 완성하고 NotebookLM에 바로 명령합니다.** M5-08·M6-01·M6-02가 끝나면 테스트·배포의 실제 결과만 해당 칸에 덧붙입니다. MD 자체가 제출 정본입니다.
>
> 문장마다 성격을 표시합니다. `[사실]`은 값·기준 시점·원문 링크가 있는 내용, `[가설]`은 아직 고객에게 확인하지 않은 내용, `[검증]`은 실제로 눌러 본 테스트·인터뷰·설문 결과입니다. 숫자·고객 수·매출·시장 규모를 지어내지 않습니다.

## 이 순서로 쓰는 이유

사업계획서는 좋은 아이디어를 길게 소개하는 글이 아니라, **근거 → 고객 문제 → 해결 방법 → 작은 실행 → 고객 검증 → 다음 결정**이 연결되는 문서입니다. Lean Canvas의 9칸을 모두 쓰되, 각 칸을 고객·데이터·MVP·측정 계획으로 연결합니다. 그래서 구현 전에 8개 장의 MD를 만들고, 실제 테스트 결과가 나오면 검증 상태만 바꿉니다. NotebookLM은 이 정본 MD를 시각화하는 선택 도구입니다.
