# 방문자가 얼마나 쓰는지 보기 — GA4 가이드 (수업 후 참고용)

> 오늘 배포한 주소에 붙이는 방법입니다. 수업 시간에는 필수가 아닙니다.
> 확인일 2026-09-17 · 출처 [Google Analytics 4 개발자 문서](https://developers.google.com/analytics/devguides/collection/ga4)

## 1. 두 가지 선택지

| 방법 | 장점 | 비고 |
|---|---|---|
| **Google Analytics 4** | 유입 경로·이벤트 분석이 자세함 | Google 계정 필요 |
| **Vercel Web Analytics** | Vercel 프로젝트에서 켜기만 하면 됨 | Hobby에 월 5만 이벤트 포함 · 프로젝트의 Analytics 탭 안내를 따릅니다 |

## 2. GA4 붙이는 순서

1. analytics.google.com → **관리 → 계정 만들기 → 속성 만들기**.
2. **데이터 스트림 → 웹** → 내 배포 주소(`https://이름.vercel.app`) 입력.
3. 만들어진 **측정 ID(G-로 시작)** 를 복사합니다. 이 값은 페이지에 공개되는 값이라 비밀키가 아닙니다.
4. Claude에게 요청합니다:

> 측정 ID G-____로 GA4 기본 태그(gtag.js)를 index.html의 head 안에 넣어줘. 다른 코드는 바꾸지 마. 그리고 「계산하기」 버튼을 누를 때 calculate_click 이벤트 하나를 보내줘. 이름·이메일·금액 같은 개인정보는 이벤트에 넣지 마.

5. GitHub에 다시 올려 **재배포** → 배포 주소를 열고 GA4의 **보고서 → 실시간**에서 내 방문이 보이는지 확인합니다.

## 3. 주의

- 개인정보(이름·연락처·계좌·실제 금액)를 이벤트 값으로 보내지 않습니다.
- 실제 서비스로 공개하면 수집 항목을 알리는 안내 문구(개인정보 처리 안내)를 준비합니다.
- 측정이 안 보이면: 재배포가 Ready인지 → 시크릿 창으로 방문했는지 → 광고 차단 확장이 막는지 순서로 봅니다.
