# 서버가 필요해지면 — Railway 가이드 (수업 후 참고용)

> **오늘 수업에서는 실행하지 않습니다.** 강의실 PC는 꺼지면 지워지고, 서버에는 요금·키 관리가 따라옵니다.
> 확인일 2026-09-17 · 출처 [Railway 요금제](https://docs.railway.com/reference/pricing/plans) · 요금은 자주 바뀌니 가입 화면에서 다시 확인하세요.

## 1. 언제 서버가 필요한가

| 하고 싶은 것 | 브라우저만으로 되나 | 이유 |
|---|---|---|
| LLM·증권사·유료 API 호출 | ❌ | 키가 브라우저 코드에 노출됩니다 |
| 매일 정해진 시간에 자동 수집 | ❌ | 누군가 페이지를 열지 않아도 돌아야 합니다 |
| 여러 사람의 데이터 저장·로그인 | ❌ | DB와 인증이 필요합니다 |
| 입력 → 계산 → 결과 표시 | ✅ | 오늘 만든 방식으로 충분합니다 |

## 2. 구조

```
사용자 브라우저 → Vercel(오늘 만든 화면) → Railway(작은 API 서버, 키 보관) → 외부 API
```

화면은 Vercel에 그대로 두고, **키가 필요한 요청만** Railway 서버가 대신 보냅니다.
(같은 역할을 Vercel 안의 `/api` 함수로 만드는 방법도 있습니다. 요청이 적고 짧으면 그쪽이 더 간단할 수 있습니다.)

## 3. 순서

1. **작은 서버 하나만** 만듭니다. 기능은 「화면이 보낸 값으로 외부 API를 부르고 결과만 돌려주기」 하나.
2. 키는 코드에 쓰지 않고 Railway 프로젝트의 **Variables(환경변수)** 에 넣습니다.
3. 서버에 공개 주소(도메인)를 만들고, 내 Vercel 주소에서만 요청을 받도록 **CORS**를 설정합니다.
4. 화면의 호출 주소를 그 서버 주소로 바꾸고 Vercel에 재배포합니다.
5. 사용량·비용 알림을 켜고, 수업용·연습용 키는 쓰고 나면 폐기합니다.

## 4. 요금 (2026-09-17 공식 문서 기준)

- **Free:** 월 $0 · 매월 $1 크레딧
- **Trial:** 1회 $5 크레딧
- **Hobby:** 월 $5 · $5 사용량 포함
- 크레딧이 0이 되면 **서비스가 멈춥니다.** 결제 수단 조건은 가입 시점 화면을 확인하세요.

## 5. Claude에게 시킬 때

> 내 Vercel 화면(주소 __)은 그대로 두고, 외부 API 키가 필요한 요청 하나만 대신 보내는 작은 API 서버를 Railway에 올리고 싶어. 키는 환경변수로만 읽고, 내 Vercel 주소에서 온 요청만 받게 해줘. 먼저 필요한 파일·환경변수 이름·예상 비용 확인 항목을 설명하고, 키 값은 나에게 묻지 마.

> 🔒 키·토큰은 채팅·코드·GitHub에 붙이지 않습니다. Railway 화면의 Variables 입력칸에 직접 넣습니다.
