# 저니맵 — 한 사람 · 한 시나리오 (M5-04)

- 시나리오: 적금 만기로 1,200만원을 받은 민지가 "이 돈을 계속 예금에 둬도 되나" 고민하다가, 지인이 공유한 링크로 판단 도구를 써보고 다음 행동을 정하기까지
- 처음 들어오는 순간: 적금 만기 알림을 받고 "이 돈, 그냥 또 예금에 넣어도 되나?"라는 의문이 든 순간
- 마지막에 얻는 것: 최근 몇 년간 예금금리가 물가상승률보다 낮았던 해가 몇 번인지 확인하고, 지금 예금만으로 괜찮은지 판단할 근거

|단계|행동|생각|감정 1~5|다음 단계로 가는 이유|기회|
|---|---|---|---|---|---|
|1|지인이 공유한 링크를 눌러 랜딩페이지 도착|"이게 뭐길래 공유했지"|3|첫 화면에 "예금만으로 충분할까?"라는 핵심 질문이 바로 보여서|랜딩 최상단에 문제 문장을 그대로 노출|
|2|"확인하기" 버튼을 눌러 앱 화면 진입|"복잡한 거 아니겠지"|3|입력할 게 거의 없어 보여서 부담 없이 클릭|입력 없이 최신 연도 기본값으로 바로 결과를 보여줌|
|3|결과 화면에서 "2개년(2021·2022) 마이너스"와 "한국 주가지수 연 수익률 범위(+40%~−18.86%)"를 함께 확인|"예금이 밀린 해가 있었네... 근데 주가지수는 오르내림이 크네, 이건 더 무서운데"|2|숫자는 봤지만 "그래서 뭘 해야 하는지" 감이 안 오고, 변동폭을 보니 오히려 더 막막해짐|숫자 옆에 쉬운 해석 문장 한 줄 추가(예: "변동이 크다고 무조건 나쁜 건 아니에요")|
|4|결과를 지인에게 다시 공유하거나 그냥 창을 닫음|"예금 말고 다른 방법도 있다는 건 알겠는데, 아직 무서워서 더 찾아봐야겠다"|3|결론까진 못 내렸지만 새로운 정보를 얻었다고 느껴서|공유 버튼과 "다음에 무엇을 확인하면 좋을지" 체크리스트 제공|

- **감정 최저점**: 단계 3 → 기능 후보: 결과 숫자 옆에 쉬운 해석 문장 붙이기(예: "물가를 못 따라간 해가 있었다는 뜻이에요", "변동이 크다고 무조건 나쁜 건 아니에요")
- **떠나는 순간**: 단계 3~4, "그래서 나는 뭘 해야 하지... 무서운데"라는 답답함(계산이 아니라 두려움이 진짜 장벽이라는 가장 위험한 가정과 연결) → 붙잡을 장치: 특정 상품 추천 대신 "다음에 확인해볼 것" 체크리스트 제공(투자 상품 추천 아님, 방향 제시만)

## 단계 전환 이유 — 왜 이렇게 넘어가는가

- **1→2**: 랜딩 첫 화면의 핵심 질문("예금만으로 충분할까?")에 흥미가 생기고, 입력 부담이 없어 보여 큰 고민 없이 앱 화면으로 이동함 (가설: 실제 클릭률·체류시간은 배포 후 별도 확인 필요)
- **2→3 (감정 최저점의 원인)**: 2단계에서 "복잡한 거 아니겠지"라는 낮은 기대로 클릭했는데, 3단계 결과 화면은 "2개년 마이너스", "+40%~−18.86%" 같은 숫자만 먼저 보여줌. 숫자 자체의 의미(좋은지 나쁜지)를 사용자가 스스로 해석해야 하는 지점이라 감정이 3→2로 떨어짐. 즉 "정보가 없어서"가 아니라 "정보는 받았는데 해석이 안 돼서" 감정이 낮아진 것 (가설: 실제 사용자가 이 지점에서 동일하게 헷갈려하는지는 검증 안 됨 — F-02 해석 문장으로 완화를 시도했지만 사용자 반응은 미확인)
- **3→4**: F-02 해석 문장으로 숫자의 의미는 어느 정도 이해하지만, "그래서 나는 지금 뭘 해야 하나"라는 결론·다음 행동이 여전히 없어 완전히 해소되지 못한 채 공유하거나 창을 닫는 쪽으로 넘어감 (가설: F-03 체크리스트가 이 지점을 실제로 붙잡아 줄지는 구현·검증 전)
