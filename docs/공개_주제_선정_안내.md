# 오늘의 주제 선정 · 공개 가능한 프로토타입

오늘은 수업 뒤 공유·배포해도 되는 금융·생활금융 주제로 만듭니다. 공개 데이터, 공개 기사 제목과 짧은 근거, 직접 만든 예시 값만 사용합니다.

## 오늘 사용하지 않는 것

- 개인 계좌·실제 거래·개인정보
- 재직 회사·고객의 비공개 자료
- 유료 증권 리포트 원문과 권리가 불분명한 화면·이미지

## 실제 본인 사업은 수업 뒤 이어 갑니다

아이디어는 대부분 이미 머릿속에 있습니다. 사업은 아이디어를 작게 실행하고 고객 반응과 근거로 고칠 때 앞으로 갑니다. 오늘은 공개 가능한 문제를 한 화면·F-01 하나로 직접 실행합니다. 실제 사업은 별도 비공개 작업공간에서 권한·라이선스·민감정보를 확인하고 같은 순서로 이어 갑니다.

주제 후보를 고를 때 `공개 가능 자료인가 / 공개하면 안 되는 정보는 무엇인가 / 오늘 데모 범위 / 실제 사업에서 추가 확인할 것`을 `docs/topic.md`에 남깁니다.
