# 근거 찾기 가이드 — 리포트·통계·논문으로 확인하기

> AI가 쓴 문장은 **근거가 아닙니다.** 근거는 내가 **링크를 직접 열어서 확인한 자료**뿐입니다.
> 수업 중에는 **린캔버스의 문제·고객 칸에 근거 2개**까지만 확인합니다. 더 깊은 리서치는 Lv2·Lv3와 수업 후에 합니다.

## 1. 근거의 등급

| 등급 | 자료 | 쓰는 법 |
|---|---|---|
| A · 1차 공식 | 법령, 정부·공공기관 통계와 보도자료, 한국은행·금융감독원·금융위원회 자료 | 숫자와 제도 기준값은 여기서만 가져옵니다 |
| B · 연구 | 학술 논문, 국책·금융 연구기관 보고서 | 원인·경향 설명에 씁니다. 표본과 연도를 같이 적습니다 |
| C · 언론·업계 | 기사, 증권사·컨설팅 리포트, 업계 설문 | 흐름 파악용. 원자료(A·B)를 따라가 확인합니다 |
| D · 확인 불가 | 출처 없는 블로그, AI가 만든 문장, 링크가 안 열리는 인용 | **근거로 쓰지 않습니다** |

## 2. 어디서 찾나 (공개 자료)

| 찾는 것 | 먼저 볼 곳 |
|---|---|
| 금리·환율·물가 등 경제 통계 | 한국은행 경제통계시스템 ecos.bok.or.kr · 국가통계포털 kosis.kr |
| 공공 데이터 파일 | 공공데이터포털 data.go.kr |
| 금융 정책·제도 발표 | 금융위원회 fsc.go.kr · 금융감독원 fss.or.kr |
| 금융상품 비교·소비자 정보 | 금융감독원 금융소비자 정보포털 파인 fine.fss.or.kr · 한국소비자원 kca.go.kr |
| 제도 기준값(세금·환불 규정 등) | 국가법령정보센터 law.go.kr · 해당 기관 공식 안내 |
| 연구 보고서 | 한국금융연구원 kif.re.kr · 한국개발연구원 kdi.re.kr |
| 논문 | RISS riss.kr · Google Scholar scholar.google.com · DBpia dbpia.co.kr(유료 논문 많음) |

## 3. 근거 카드 — 하나에 4가지를 꼭 적습니다

| 항목 | 예시 |
|---|---|
| **값과 단위** | 「○○% 」「○○만 명」 |
| **시점** | 조사·기준 연월 (발표일과 구분) |
| **출처** | 기관·문서 제목 + 링크 |
| **이 근거가 말해주는 것 / 말해주지 않는 것** | 「20대 전체 기준이라 사회초년생만의 수치는 아님」 |

## 4. 프롬프트 (8블록 틀 · `docs/prompt_guide.md` 1절)

**① 문제·고객 근거 2개 (수업 중 · 약 6분)**
```
[역할] 리서치 조교. 확인한 것과 추측을 엄격히 구분한다.
[목표] 린캔버스의 문제·고객 칸을 뒷받침할 근거 2개를 확보한다.
[입력] docs/topic.md
[진행]
1. 우선순위대로 찾아: 법령·정부·공공기관·한국은행 자료 > 연구 보고서·논문 > 언론·업계.
2. 근거마다 링크를 네가 다시 열어 값·시점·제목이 실제 문서에 있는지 대조해.
3. 대조에 실패한 자료는 확인 불가로 표시하고 목록에서 빼.
[출력] docs/evidence.md — 표 열: 번호 / 등급(A~D) / 값과 단위 / 기준 시점 / 기관·문서 제목 / 링크 / 말해주는 것 / 말해주지 않는 것
[저장 전 자가 점검] 모든 행을 링크로 대조했는가 · 수치를 추정하지 않았는가 · 말해주지 않는 것을 적었는가
[지킬 것] 유료 논문·기사 본문을 복사하지 않는다 · 존재를 확인하지 못한 문서를 쓰지 않는다.
[끝나면 보고] 내가 직접 열어볼 링크 순서.
```
→ 그다음 **내가 직접 링크를 열어** 값이 보이는지 확인하고 「확인했어」라고 말합니다.

**② 사실과 가설 나누기**
```
[역할] 린캔버스 검수자.
[목표] 근거가 있는 칸만 사실로 표시한다.
[입력] docs/lean_canvas.md · docs/evidence.md
[진행] 칸마다 근거 번호가 있으면 사실(번호), 없으면 가설로 표시하고, 근거가 말해주지 않는 범위까지 쓴 문장은 좁혀서 고쳐.
[출력] docs/lean_canvas.md(칸 / 문장 / 사실·가설 / 근거 번호)
[저장 전 자가 점검] 사실로 표시한 칸이 모두 근거 번호를 갖는가 · 확대 해석이 없는가
```

**③ Lv2 · 리포트 3개로 시장과 기존 대안**
```
[역할] 시장 조사원.
[목표] 기존 대안 2개와 시장을 다룬 보고서 3개로 내 가치제안을 점검한다.
[진행]
1. 같은 불편을 해결하는 기존 서비스·방법 2개: 해주는 것 / 못 하는 것 / 링크.
2. 보고서 3개: 발행 기관 / 연도 / 핵심 수치 1개(값·단위·시점) / 링크. 광고성 글은 제외.
[출력] 대안 비교표 + 보고서 근거 카드 3개
[저장 전 자가 점검] 링크 대조 · 수치의 기준 시점 기재 · 광고성 자료 제외
```

**④ Lv3 · 논문으로 원인 확인**
```
[역할] 연구 보조원.
[목표] 내 문제의 원인을 다룬 학술 논문 2편을 근거 카드로 만든다.
[진행]
1. RISS·Google Scholar 기준으로 찾는다.
2. 제목 / 저자 / 연도 / 학술지 / 표본(대상·수) / 핵심 결과 한 문장 / 링크.
3. 초록만 확인했으면 초록 기준이라고 표시한다.
[출력] 논문 근거 카드 2개
[저장 전 자가 점검] 논문이 실제로 존재하는가(링크로 확인) · 표본과 연도를 적었는가 · 본문을 길게 옮기지 않았는가
```

**⑤ 내 주장이 근거보다 앞서가지 않는지**
```
[역할] 주장 검수자.
[목표] 서비스 소개 문장을 근거 수준에 맞춘다.
[입력] 소개 문장 · docs/evidence.md
[진행] 문장마다 가능(근거로 확인됨) / 제한(조건이 필요 · 조건 문구 제안) / 금지(근거 없음·과장·투자 권유로 읽힘)로 분류하고, 금지 문장은 대체 문장을 제안해.
[출력] 표(문장 · 분류 · 근거 번호 · 수정안)
```

## 5. 지킬 것

- 유료 논문·리포트의 **본문을 복사해 붙이지 않습니다.** 제목·링크·짧은 요약만 남깁니다.
- 기사 본문 전체를 저장하거나 배포하지 않습니다.
- 사람에게 물어볼 때(인터뷰·설문) 이름·연락처는 저장하지 않습니다.
- 근거 수치로 **투자 권유 문장을 만들지 않습니다.**
