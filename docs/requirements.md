# 개발 설계 — 요구사항 명세

이번 기능은 F-01 하나입니다. R-01/R-02/R-03은 그 기능이 만족해야 할 정상·빈값·오류 요구사항입니다. 세 개의 별도 기능이라는 뜻이 아닙니다. 다음 기능은 F-02와 새 요구사항 ID로 추가합니다.

## 기능과 구조

- 기능 F-01 / 해결할 사용자 행동: 사용자가 화면에 들어와 예금금리·물가상승률·한국 주가지수 연 수익률 비교 결과를 확인하고 "예금만으로 충분한지" 판단 신호를 얻는다
- 입력 데이터·출처·형식: `data/public/kor_macro_annual.js`(연도별 예금금리·물가상승률, 2010~2025) + OECD 한국 주가지수(SPASTT01KRA661N, 2010~2025 연간)를 연도별 수익률로 미리 가공한 정적 파일 데이터. 사용자 입력은 (선택) 비교 시작·종료 연도. S&P500은 S&P Dow Jones Indices의 재배포 금지 라이선스로 제외
- 입력 → 처리 → 출력 → 저장 흐름: data.js 로드 → 기간 선택(또는 기본값 2021~2025) → 연도별 예금금리−물가상승률 계산 후 마이너스 연도 수 카운트 → 같은 기간 한국 주가지수 연 수익률의 최고~최저 범위 계산 → 화면에 표시(서버 저장 없음, 계산은 매번 새로 실행)
- 화면·파일·함수/API 구성: `index.html`(랜딩) → `app.html`(계산기 화면) → `app.js`(계산 로직: `calcDepositVsInflation()`, `calcStockRange()`, `validateRange()`) → `data.js`(정적 데이터: `KOR_MACRO_ANNUAL`, `KR_STOCK_INDEX_ANNUAL`)
- 외부 연결·인증·키 위치 (값은 적지 않음): 없음. fetch·API 키 없이 정적 파일만 사용(강의실 네트워크 문제 회피)
- 구현 순서 / 제외 범위: ① `kor_macro_annual.js`를 `data.js`로 복사 ② OECD 한국 주가지수를 연 수익률로 변환해 `data.js`에 추가 ③ 계산 함수 작성 ④ 화면 연결. 제외: S&P500 등 해외 지수(라이선스 문제), 표준편차 기반 리스크, 로그인·개인화, 서버 저장

|기능 ID|요구사항 ID|시작 상태·사용자 행동|입력·조건|기대 출력·완료 기준|빈값·오류 안내|구현 대상|연결 테스트 ID|
|---|---|---|---|---|---|---|---|
|F-01|R-01 정상|사용자가 `app.html`에 들어와 기본 기간(2021~2025)으로 결과를 본다|기간을 선택하지 않거나 유효한 시작연도<종료연도를 선택|"N개년 마이너스"와 "한국 주가지수 연 수익률 범위 +a%~−b%"가 출처·기준 시점과 함께 화면에 표시됨|해당 없음(정상 케이스)|app.html, app.js, data.js|UT-01 / IT-01|
|F-01|R-02 빈값|사용자가 기간 드롭다운에서 "선택 안 함" 상태로 "확인"을 누른다|시작연도 또는 종료연도가 비어 있음|계산 결과를 표시하지 않고 "비교할 기간을 선택하세요" 안내만 표시|"비교할 기간을 선택하세요" 문구, 이전 결과 화면에 남기지 않음|app.js 입력 검증|UT-02 / IT-02|
|F-01|R-03 오류|사용자가 시작연도가 종료연도보다 늦게 선택하거나 data.js 로드에 실패한다|시작연도>종료연도, 또는 data.js 누락·손상|계산을 실행하지 않고 오류 안내만 표시, 화면이 깨지지 않음|"기간을 다시 확인해주세요" 또는 "데이터를 불러오지 못했습니다" 문구|app.js 입력 검증·오류 처리|UT-03 / IT-03|

선택 기능에 경계값·중복·저장·계산 등 추가 조건이 필요하면 R-04 이후를 더합니다. 구현 편의 때문에 사용자 완료 기준을 바꾸지 않습니다.

> 선택한 MVP 기능 F-01만 개발할 요구사항 명세를 만들어줘. 정상·빈값·오류별로 요구사항 번호, 입력, 사용자 행동, 출력, 실패 안내, 검증 가능한 완료 기준을 적어줘. 데이터→처리→화면 흐름과 필요한 파일/API·인증 위치를 설명해줘. 키 값은 문서에 쓰지 마. 아직 구현하지 말고 연결되는 단위·통합 테스트 설계서를 먼저 작성해줘.
