# 주제 (M5-01)

- **주제 한 문장**: 사회초년생이 첫 월급을 저축하기 시작할 때, 예금금리와 물가상승률의 격차가 해마다 달라지고 때로는 마이너스였다는 것을 모른 채 예금만으로 충분한지 판단하지 못한다.
- 대상 한 사람: 취업 후 첫 월급을 받아 목돈을 모으기 시작한 20대 후반 사회초년생
- 이 주제가 나온 숫자(근거 번호): D1(예금금리 2.734%, 2025), D2(소비자물가 상승률 2.123%, 2025)
- 지금은 어떻게 해결하나(기존 대안): 은행 앱의 단순 이자 계산기로 명목 이자만 확인하거나, 주변 사람 조언에 의존
- 가장 위험한 가정 1개: 사용자가 "예금금리가 물가상승률보다 높으면 무조건 이득"이라고 단순하게 받아들이지 않고, 실질 자산 증가라는 개념에 관심을 가질 것이다
- 앱에 쓸 데이터: `data/public/kor_macro_annual.js` (예금금리·소비자물가 상승률, 2010~2025)
- 오늘 미룰 것: 주식·채권·부동산 등 다른 자산군 비교, 개인별 세율·세후 이자 계산, 은행별 실제 상품 비교
