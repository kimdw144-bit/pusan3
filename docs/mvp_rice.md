# MVP 범위와 RICE — 먼저 만들 기능 하나

MVP 목표는 사용자가 핵심 일을 한 번 끝낼 수 있는 가장 작은 작동 버전입니다. 버튼 하나만 보이는 화면과 구분합니다.

1. 저니맵의 막힘에서 기능 후보를 3개 이내로 고릅니다.
2. 후보별로 RICE를 비교합니다. R은 같은 기간의 사용자 수/이용 건수, I는 영향, C는 근거 확신, E는 필요한 작업량입니다.
3. 점수 = R × I × C ÷ E. C는 50%=0.5처럼 계산합니다. E는 0보다 커야 합니다. 수업에서는 작업량 단위를 인시로 통일해 비교하며 원래 방식의 인월을 축소 적용한 것입니다.
4. 근거가 없으면 추정이라고 씁니다. 점수가 높아도 데이터·인증·시간 제약을 해결할 수 없으면 범위를 줄이거나 다음 후보를 고릅니다.

|후보|사용자 문제|R: 같은 기간|I|C: 비율|E: 인시|점수|근거/추정·의존성|선정|
|---|---|---:|---:|---:|---:|---:|---|---|
|F-01|예금·물가·한국 주가지수 격차를 몰라 예금만으로 충분한지 판단 못 함 (저니맵 3단계 최저점의 원인)|30명(추정: 오늘 랜딩 방문자)|3|0.9|6|13.5|R,C: 추정 · I: 저니맵 최저점을 직접 해결하지 않으면 다른 기능이 무의미(의존성 최상위) · 데이터는 D1,D2+OECD 한국 주가지수 확인됨|✅|
|F-02|결과 숫자만 보고 "좋은 건지 나쁜 건지" 해석을 못 함 (저니맵 3단계 감정 최저점)|30명(추정)|2|0.5|1|30|R: 추정 · C: 해석 문장이 실제 이해를 도울지 검증 안 됨 · **F-01 결과 화면이 있어야 붙일 수 있음(F-01 의존)**|다음|
|F-03|결론 없이 이탈(저니맵 4단계)|30명(추정)|1|0.4|1.5|8|R,C: 추정 · **F-01·F-02 이후에나 의미 있음(의존)**|다음|

**계산식** (후보마다 한 줄)
- F-01: 30명 × 3 × 0.9 ÷ 6시간 = 13.5점
- F-02: 30명 × 2 × 0.5 ÷ 1시간 = 30점
- F-03: 30명 × 1 × 0.4 ÷ 1.5시간 = 8점

**선택**
- 점수 1등 기능: F-02 (30점)
- 오늘 선택한 기능(F-01): 예금금리·물가상승률·한국 주가지수 연 수익률(최고~최저 범위) 비교
- 선택 이유(1등과 다르면 왜 다른지): F-02는 점수는 더 높지만 F-01의 결과 화면이 있어야 붙일 수 있는 **보완 기능**이라 오늘 F-01 없이는 만들 수 없음. F-01을 먼저 완성해야 F-02·F-03이 다음 기회에라도 의미가 있음
- 오늘 미룬 기능: F-02(해석 문장), F-03(체크리스트) — 시간이 남으면 F-01 완성 후 추가

- 이번 핵심 기능: 예금금리·물가상승률·한국 주가지수 연 수익률을 한 화면에서 비교해 "예금만으로 충분한지" 판단 신호를 주는 계산기
- 사용자가 완료할 행동: 화면에 들어가서(입력 없이 기본값으로) 예금·물가·한국 주가지수 비교 결과를 확인한다
- 입력 → 처리 → 결과: (선택) 비교 기간 선택 → 연도별 예금금리−물가상승률, 한국 주가지수 연 수익률 계산 → 마이너스였던 연도 수 + 주가지수 최고~최저 수익률 범위를 나란히 표시
- 이번에 제외할 기능: 해석 문장(F-02), 다음 행동 체크리스트(F-03), S&P500 등 해외 지수(라이선스 문제로 제외), 표준편차 기반 정밀 리스크, 개인 맞춤 저축 시뮬레이션
- 완료 기준: R-01(정상: 값 계산되어 표시) · R-02(빈값 안내) · R-03(오류 안내)까지 직접 확인
- 필요한 선행 연결: `data/public/kor_macro_annual.js`를 `data.js`로 복사 + OECD 한국 주가지수(SPASTT01KRA661N)를 연 수익률로 변환한 데이터 추가

> 린캔버스와 저니맵에서 나온 기능 후보를 최대 3개로 정리해줘. 같은 기준의 RICE로 비교하되 수치의 근거와 추정을 구분하고, 데이터 접근·작업량·선행 기능도 확인해줘. 이번 수업에서 실제로 동작시킬 MVP 기능 하나와 제외 범위를 제안해줘. 선택한 뒤 요구사항 명세로 넘어가자.
