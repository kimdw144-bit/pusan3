# MVP 범위와 RICE — 먼저 만들 기능 하나

MVP 목표는 사용자가 핵심 일을 한 번 끝낼 수 있는 가장 작은 작동 버전입니다. 버튼 하나만 보이는 화면과 구분합니다.

1. 저니맵의 막힘에서 기능 후보를 3개 이내로 고릅니다.
2. 후보별로 RICE를 비교합니다. R은 같은 기간의 사용자 수/이용 건수, I는 영향, C는 근거 확신, E는 필요한 작업량입니다.
3. 점수 = R × I × C ÷ E. C는 50%=0.5처럼 계산합니다. E는 0보다 커야 합니다. 수업에서는 작업량 단위를 인시로 통일해 비교하며 원래 방식의 인월을 축소 적용한 것입니다.
4. 근거가 없으면 추정이라고 씁니다. 점수가 높아도 데이터·인증·시간 제약을 해결할 수 없으면 범위를 줄이거나 다음 후보를 고릅니다.
