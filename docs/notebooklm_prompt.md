# NotebookLM 슬라이드 명령 · M6-05에서 사용

먼저 `docs/business_plan.md`만 NotebookLM에 올립니다. 그다음 아래 명령을 맞춤설정 칸에 그대로 붙입니다.

```text
업로드한 business_plan.md만 근거로, 한국어 발표자 슬라이드 10장 이내를 만들어줘. 새 숫자·시장 규모·고객 사례·출처를 만들지 말고, 문서의 [사실]·[가설]·[검증] 표시를 유지해. 각 장은 한 메시지와 하나의 시각 구조만 사용해. 순서는 ① 데이터 근거 기반 현황 ② 문제와 기존 대안 ③ 페르소나와 저니맵의 불편 순간 ④ 초기 고객·TAM/SAM/SOM·가치 제안 ⑤ MVP·RICE 선택 ⑥ 요구사항과 UI/랜딩 설계 ⑦ 채널·마케팅 실험 ⑧ 수익·비용 가설 ⑨ 핵심 지표·마일스톤·테스트/배포 결과 ⑩ 한계와 다음 고객 검증으로 해. 각 장 하단에 사용한 문서 내 출처 또는 「가설·리서치 필요」를 작게 표시해. 검증하지 않은 내용을 성과처럼 말하지 마.
```

생성 뒤에는 각 장의 숫자·출처·가설 표시가 `business_plan.md`와 같은지 직접 대조합니다. 다르면 해당 장을 다시 만들거나 제거합니다.
