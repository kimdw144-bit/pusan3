# 데이터 가이드 — 숫자에서 주제를 찾는 세 경로

> 오늘은 아이디어를 머리에서 꺼내지 않고 **숫자에서** 찾습니다.
> 숫자를 보고 「누가 이 숫자 때문에 언제 곤란한가」를 묻는 것이 주제 찾기의 전부입니다.
> 주제가 없으면 `docs/data_cards.md`의 카드 하나로 시작하세요. **이 가이드는 정답지가 아니라 가장 빠른 출발점**입니다. 필수 결과를 저장한 뒤 시간이 남거나 더 깊이 보고 싶다면, Claude에게 「지금 단계에 맞는 프레임워크나 방법론을 3가지 찾아, 목적·입력·산출물·내 주제 적합성을 비교해줘」라고 요청하세요. 제안받은 방법은 원문·적용 범위를 확인한 뒤 한 가지만 선택하고, 기존 필수 산출물을 바꾸기 전에는 전·후를 비교합니다.

## md 파일 다루는 법 (처음이라면)

| 하고 싶은 것 | 이렇게 |
|---|---|
| 내용 보기 | Claude에게 「docs/persona.md를 표로 보여줘」 — 대화창에서 표로 보입니다 |
| 고치기 | Claude에게 「docs/persona.md의 계기 칸을 ○○로 바꿔줘. 바꾸기 전과 후를 보여줘」 |
| 직접 열기 | Windows 메모장 · Mac 텍스트 편집기 (`|`와 `#`가 그대로 보이는 게 정상입니다) |
| 보기 좋게 보기 | GitHub에 올린 뒤 저장소에서 파일을 누르면 표가 정리되어 보입니다 |

## 0. 가장 빠른 길 — 이미 받아 둔 공개 데이터

`data/public/` 폴더에 **키 없이 받을 수 있고 다시 나눠 써도 되는** 공개 데이터 6종을 미리 받아 두었습니다(2026-09-18 수집).
강의실 인터넷이 느려도 이 파일로 바로 시작할 수 있습니다. 목록과 출처는 `data/public/README.md`에 있습니다.

| 파일 | 무엇 | 이런 주제에 |
|---|---|---|
| `fx_krw_daily.js` | 원화 환율 일별(달러·엔·유로·위안) | 여행 환전, 해외 직구, 해외 송금 |
| `kor_macro_annual.js` | 한국 연간 지표 8종(물가·예금금리·대출금리·실질금리·청년 실업률·원/달러·65세 이상 비중·1인당 GDP) | 생활비, 저축, 대출, 취업 준비, 노후 |
| `kor_cpi_monthly.js` | 소비자물가 전년 대비(월별) | 물가 체감, 장바구니 |
| `kor_rates_monthly.js` | 장기금리·3개월 금리(월별) | 예적금, 대출 이자 흐름 |
| `usdkrw_monthly.js` | 원/달러 월평균(2021~) | 환율 장기 흐름 |
| `sbiz_bsi_monthly.js` | 소상공인 체감·전망 경기지수(업종·지역) | 1인 사업자, 자영업 |

앱에서 쓰는 법: 쓸 파일(예: `data/public/kor_macro_annual.js`)을 **프로젝트 맨 위의 `data.js`로 복사**하고 `app.html`에 `<script src="data.js"></script>`를 넣은 뒤 `window.KOR_MACRO_ANNUAL.rows`를 읽습니다. 폴더 없이 올릴 수 있고 서버·키·fetch가 필요 없습니다. **화면에 출처와 기준 시점을 꼭 표시합니다.**

## 1. 세 경로

| 경로 | 어디서 | 앱에 넣는 법 | 주의 |
|---|---|---|---|
| **① 키 없는 API** | World Bank(`api.worldbank.org`) · Frankfurter 환율(`api.frankfurter.dev`) · OECD · 유럽중앙은행 | 브라우저에서 바로 불러오기. **실패하면 `data/public` 값을 보여 줌** | 강의실 네트워크가 막히면 실패할 수 있음 |
| **② 파일 받아 data.js로** | `data/public/` · 공공데이터포털 **파일데이터**(CSV) · FRED(원/달러 등 연준 자료) | CSV를 Claude에게 주고 「data.js로 바꿔줘」 | 파일마다 이용 조건 확인 · 출처 표기 |
| **③ 근거 문서** | 한국은행·금융위원회·금융감독원 보도자료 · 연구기관 보고서 · 증권사·업계 리포트 | 앱에는 안 넣고 `docs/data_sources.md` 근거표에만 | 링크를 직접 열어 값·시점을 확인 · 본문 복사 금지 |

**믿는 순서**: 공식 통계·기관 자료 > 연구 보고서·논문 > 기사. 기사는 원자료까지 찾아 들어갑니다.

## 2. 쓰지 않는 것

| 쓰지 않음 | 이유 |
|---|---|
| 한국은행 ECOS·KOSIS·금감원 금융상품 API | 인증키가 필요합니다(수업에서 키를 받지 않습니다) |
| 한국 개별 종목 주가 원데이터 | 한국거래소 자료는 제3자 재배포가 금지되어 공개 앱에 넣을 수 없습니다 |
| 업비트 시세 반복 호출 | 브라우저 요청이 10초에 1회로 제한되어 강의실에서 함께 쓰면 막힙니다 |
| 기사·리포트 본문 | 저작권. 제목·링크·짧은 근거 한 문장만 |

## 3. 숫자 → 주제 (M5-01)

1. 숫자 2개를 고릅니다. 표: 번호 / 값과 단위 / 기준 시점 / 기관·문서 / 링크 / 말해주는 것 / **말해주지 않는 것**.
2. 숫자마다 「누가 이 숫자 때문에 언제 곤란한가」를 한 줄씩 씁니다.
3. 후보 3개를 비교합니다: 누가 · 언제 · 지금은 어떻게 해결 · 오늘 한 화면으로 가능한가 · 쓸 데이터.
4. 하나를 골라 **「[누가] [언제] [무엇 때문에] [무엇을] 못 한다」** 한 문장으로 씁니다.

> 근거가 안 나오면 「아무도 모르니 기회」로 읽지 않습니다. 가설로 남기고, 나중에 사람에게 물어 확인합니다.

## 4. 지표마다 알아둘 것 — 단위 · 주기 · 기준 시점

| 지표 | 단위 | 주기 | 읽을 때 주의 |
|---|---|---|---|
| 환율 (원/달러 등) | 1단위 외화당 원 (엔은 100엔 기준으로 읽음) | 영업일마다 | 기준환율이며 실제 환전·카드 환율과 다름 |
| 금리 (예금·대출·국채) | 연 % | 월 평균·연 평균 | 장기(10년)와 단기(3개월)는 움직임이 다름 · 평균은 내 상품 금리가 아님 |
| 소비자물가 | 전년 같은 달 대비 % | 월 | 평균이라 품목마다 다름 · 발표까지 시차 |
| 소상공인 체감지수 | 지수(100 기준) | 월 | 설문 응답 지수 · 최신 발표가 몇 달 늦음 |
| World Bank 연간 지표 | 열 이름의 단위 | 연 | 최신 연도가 늦게 채워짐 · 연 평균값 |

**변화율 = (이번 기간 − 이전 기간) ÷ 이전 기간 × 100.** 퍼센트끼리 비교할 때는 %p(퍼센트포인트)로 씁니다(예: 금리 3.5% → 3.0% = −0.5%p).
결측(빈 값)은 0으로 채우지 않고 빈칸으로 둡니다. 차트나 문장마다 **해석 1문장과 한계 1문장**을 붙입니다.

## 5. 한국은행·공공데이터포털은 이렇게 생겼습니다

| 곳 | 구조 | 수업에서 |
|---|---|---|
| 한국은행 ECOS | 통계표 → 항목 → 주기(일·월·연) → 기간. 화면 조회·파일 받기 가능, **API는 인증키 필요** | 화면에서 값 확인 → 근거표에 적기 |
| 공공데이터포털 | **파일데이터**(CSV 바로 받기) / **오픈API**(회원가입·인증키) 두 종류. 데이터마다 이용허락 범위가 다름 | 파일데이터만 사용(소상공인 지수는 이미 `data/public`에) |
| KOSIS(통계청) | 통계표 조회·파일 받기 · API는 인증키 | 화면에서 값 확인 |

## 6. 맞는 데이터가 없을 때 — 공공데이터 찾아 연결하기

`data/public`에 내 주제에 맞는 파일이 없으면 **직접 찾아서 연결합니다.** 막히면 손을 들거나 패들렛 「데이터 도움」 칸에 주제와 찾는 숫자를 적어 주세요 — 강사·보조강사가 함께 찾습니다.

| 순서 | 할 일 |
|---|---|
| 1 찾기 | Claude가 공공데이터포털 **파일데이터** · World Bank · OECD · KOSIS·한국은행(화면) · 기관 보도자료와 연구기관 공개 보고서에서 후보 3개를 찾아 표로 보여 줍니다(이름 · 제공기관 · 주기 · 최신 시점 · 키 필요 여부 · 이용 조건 · 링크). 외부 리서치는 숫자·정의·한계를 확인하는 데 쓰고, 유료 기사·리포트 본문은 저장하지 않습니다. |
| 2 고르기 | **키 없이 받을 수 있고** 이용 조건이 맞는 것 하나를 고릅니다(ECOS·KOSIS API, 공공데이터포털 오픈API는 키가 필요해 제외) |
| 3 받기 | 쉬운 길: 공공데이터포털 페이지에서 **바로 CSV가 받아지는 자료**를 고르고, 다운로드 버튼으로 받아 `data/raw/`에 넣습니다. 어떤 자료는 다운로드를 누르면 **다른 기관 사이트로 이동**합니다(예: 한국부동산원) — 그러면 그 사이트에서 받아야 해서 오래 걸릴 수 있습니다. World Bank·OECD는 Claude가 주소로 바로 받습니다. **10분 안에 못 받으면 다른 후보로** |
| 4 바꾸기 | Claude가 CSV를 읽어 필요한 열만 골라 맨 위 `data.js`로 만듭니다(출처·기준 시점·수집일 주석, 한글 깨짐 확인, 빈 값은 빈칸) |
| 5 확인 | 행 수 · 첫·마지막 값 · 단위를 원본과 대조합니다 |
| 실패하면 | 공식 자료의 숫자 몇 개를 근거표에 적고, 앱은 사용자가 직접 넣는 값으로 계산합니다 |

- Claude가 인터넷에서 파일을 받을 때 **허용을 묻는 창**이 뜨면 명령 내용을 보고 허용합니다.
- 이 과정은 5~10분 걸립니다(9/18 실측 약 9분). 찾은 자료가 내 주제와 성격이 다르면(예: 공공임대 임대료 ≠ 민간 원룸 월세) 그 차이를 「말해주지 않는 것」과 화면 한계 문구에 적습니다.

붙여넣을 명령:

```
[역할] 공공데이터 연결 도우미. 키 없이 받을 수 있고 이용 조건이 맞는 자료만 쓴다.
[목표] 내 주제에 맞는 공개 데이터를 찾아 data.js로 연결한다.
[답변 방식] 한국어로, 처음 배우는 사람이 이해할 쉬운 말로 답한다. 표를 먼저 쓰고 설명은 짧게 한다.
[입력] docs/topic.md · docs/data_guide.md
[진행]
1. 공공데이터포털 파일데이터 · World Bank · OECD · KOSIS · 한국은행 · 기관 보도자료와 연구기관 공개 보고서에서 후보 3개를 찾아 표로: 이름 / 제공기관 / 주기 / 최신 시점 / 받는 법(포털에서 바로 CSV · 외부 사이트로 이동 · API 키 필요) / 이용 조건 / 링크. 링크는 네가 다시 열어 확인한 것만. 「포털에서 바로 CSV」와 World Bank·OECD 주소를 먼저 추천해. 외부 리서치는 숫자·정의·한계를 확인하는 데만 쓰고, 유료 기사·리포트 본문은 저장하거나 복사하지 마.
2. 키가 필요한 것(ECOS·KOSIS API, 공공데이터포털 오픈API)은 빼. 내가 하나를 고른다.
3. 포털에서 바로 받는 CSV면 내가 다운로드 버튼으로 받아 data/raw/에 넣을 순서를, 외부 사이트로 가는 자료면 그 사이트에서 받는 순서를 한 단계씩 알려주고, World Bank·OECD면 주소로 받아 data/raw/에 저장해. 10분 안에 못 받으면 멈추고 다른 후보나 「실패하면」 길로 가자고 말해.
4. CSV를 읽어 필요한 열만 골라 맨 위 data.js를 만들어: window.MYDATA = { source, license, period, fetched, rows }. 한글이 깨지면 인코딩을 바꿔 다시 읽고, 빈 값은 빈칸(null)으로.
5. 행 수 · 첫 값 · 마지막 값 · 단위를 원본과 대조한 표를 보여주고, docs/data_sources.md에 이 데이터를 근거로 추가해.
[지킬 것] 키·로그인이 필요한 자료, 재배포가 금지된 자료(한국 개별 주가 등), 개인정보가 든 자료는 쓰지 않는다 · 값을 지어내지 않는다 · 프로젝트 폴더 밖에 파일을 만들지 않는다.
[끝나면 보고] 저장한 파일 · 원본과 대조한 것 · 확인하지 못한 것 · 다음 단계
```
